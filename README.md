# Mars data exploration

Two notebooks collect and explore historical Mars news and weather information. The weather CSV is included as an output artifact.

- [Mars news notebook](part_1_mars_news.ipynb)
- [Mars weather notebook](part_2_mars_weather.ipynb)
- [Weather data](mars_weather_data.csv)

Web sources and page structure can change; the scraping workflow may need maintenance before rerunning. This repository is a learning exercise, not a current weather feed.
